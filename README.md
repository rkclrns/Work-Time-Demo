# WorkTime Demo

직원과 관리자를 위한 반응형 출퇴근·근태·연차 관리 웹 데모입니다.

## 주요 기능

- 직원/관리자 데모 계정 전환
- 실시간 출퇴근 기록 및 근무시간 표시
- 월간 근무 기록과 연차 캘린더
- 직원 추가·수정·삭제
- 날짜별 근태 조회와 수정
- 연차 신청·승인·반려 알림
- Supabase 기반 공용 데모 데이터 저장

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다.

## 안내

현재 Supabase 연결은 시연을 위한 공용 데모 모드입니다. 방문자가 같은 데이터를 보고 수정할 수 있으므로 실제 서비스 전환 시 Supabase Auth와 사용자별 RLS 정책을 추가해야 합니다.
